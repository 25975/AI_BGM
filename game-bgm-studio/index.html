使用说明

1. 一句话生成：输入中文画面描述，点「解析并生成」。解析器会识别风格、场景、情绪、BPM、调性，甚至「不要鼓」。

2. 换风格不换骨架：同一个种子在不同风格下会共用和声 / 结构随机序列，便于比较配器差异。

3. 垂直分层：强度 0 只有铺底与主旋律，3 会加入合唱、铜管对位、冲击音效。段落 B 会自动加一层。

4. 无缝循环：导出时把循环末尾的混响尾音叠加回开头，并把循环点写入 WAV smpl 块。

5. 分轨：鼓 / 贝斯 / 和声 / 琶音 / 旋律可单独导出，在引擎里按战斗状态动态混音。

6. 采样：弦乐 / 断奏弦乐 / 大提琴 / 铜管 / 合唱 / 定音鼓使用 FluidR3_GM 真实录音（CC BY 3.0，by Frank Wen）；女高音使用 bevibeldesign 的 CC0 真人循环长音；其他音色为实时合成。
